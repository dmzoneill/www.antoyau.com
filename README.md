The site of a band.

## Contents

PHP pages for gigs and the next gig, news, a journal, lyrics, photo galleries,
an MP3 player, a shop, a mailing list, a shoutbox, contact details and the team.
It also links to the band's Bebo and MySpace pages.

## Tech

- PHP and MySQL
- JavaScript and Flash (`swfobject`)

This is an archive of an old site, kept for reference.
